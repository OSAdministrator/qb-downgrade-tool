=============================================================
  QuickBooks TimeWarp(R)
  Migrate QuickBooks Desktop 2023 -> 2021
=============================================================

QUICK START:

  1. Put this folder on your Desktop.
  2. Drag your .QBW file onto "Launch TimeWarp.bat".
  3. Enter the admin password and click Start.

Results go into the "Output" folder right here.
Logs are in the "logs" folder.

  - Or double-click "Launch TimeWarp.bat" to open the
    GUI first, then add files from there.

NOTES:
  - QuickBooks 2023 must be installed on this machine.
  - QuickBooks 2021 must be installed on this machine.
  - Python 3.9+ must be installed (python.org).
  - First run: QB will ask to authorize "QuickBooks TimeWarp".
    Click "Yes, always" to allow access.
